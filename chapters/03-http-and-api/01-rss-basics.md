# RSS Basics — основы RSS

## Что такое RSS

**RSS — Really Simple Syndication (простой формат распространения обновлений)** — формат, через который сайт может публиковать новые материалы в машинно-читаемом виде.

Типичные элементы RSS-ленты:

```text
Title (заголовок)
Link (ссылка)
Published Date (дата публикации)
Description (описание)
```

## RSS Feed, RSS Reader и RSS Aggregator

**RSS Feed (RSS-лента)** — поток обновлений одного источника.

**RSS Reader (RSS-ридер)** — приложение, которое читает RSS.

**RSS Aggregator / RSS Portal (RSS-агрегатор / RSS-портал)** — сервис, который собирает много RSS-лент в одном месте.

Схема:

```text
Website A (сайт A) ─┐
Website B (сайт B) ─┤
Website C (сайт C) ─┼→ RSS Aggregator (RSS-агрегатор)
Website D (сайт D) ─┘
```

## Для чего это используют

RSS особенно полезен для мониторинга:

- новостей;
- блогов;
- сайтов госорганов;
- публикаций компаний;
- отраслевых порталов;
- обновлений конкурентов.

Например:

```text
RSS Sources (RSS-источники)
↓
Collector (сборщик данных)
↓
Filter (фильтр)
↓
Rule Engine (движок правил)
↓
AI Analysis (AI-анализ)
↓
Telegram / Email
```

## RSS и API

RSS обычно проще API и ориентирован именно на публикацию обновлений.

API может позволять:

- запрашивать данные по параметрам;
- изменять данные;
- выполнять действия.

RSS обычно предоставляет последовательность публикаций для чтения.

## RSS и Web Scraping

**Web Scraping (веб-скрейпинг)** читает HTML-страницы и извлекает нужные элементы.

RSS удобнее, если источник его предоставляет, потому что формат уже структурирован.

Упрощённо:

```text
RSS available (RSS доступен)
→ обычно читаем RSS

RSS unavailable (RSS отсутствует)
→ возможно API или Web Scraping (веб-скрейпинг)
```

> [!IMPORTANT]
> ## Ключевые идеи — обязательно запомнить
>
> - **RSS Feed (RSS-лента)** — структурированный поток обновлений одного источника.
> - **RSS Reader (RSS-ридер)** читает ленты.
> - **RSS Aggregator (RSS-агрегатор)** собирает много лент в одном месте.
> - RSS удобен для автоматического мониторинга новых публикаций.
> - RSS, API и Web Scraping (веб-скрейпинг) — разные способы получения внешних данных.
