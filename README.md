## Как добавляются лекции

Присылайте Markdown-файл или текст лекции в задачу Codex. Я определю основную тему, найду подходящую главу и добавлю материал отдельным `.md`-файлом. Если лекция затрагивает несколько областей, основной файл попадёт в наиболее подходящую главу, а из связанных глав будут добавлены ссылки.

Подробные правила: [ROUTING.md](ROUTING.md).
