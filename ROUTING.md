# Правила распределения лекций

## Основной принцип

Каждая лекция хранится в одной основной главе. Глава выбирается по главной учебной цели материала, а не только по отдельным ключевым словам.

## Имена файлов

Используется формат:

```text
NN-kebab-case-title.md
```

Номер `NN` задаёт порядок лекции внутри главы. Заголовок и исходное содержание Markdown сохраняются, при необходимости добавляются навигация и ссылки на связанные главы.

## Пересечения тем

Если материал относится к нескольким главам:

1. выбирается одна основная глава;
2. в связанных главах добавляются ссылки;
3. дублирование полного текста не создаётся.

## Рабочий процесс

1. Получить Markdown-файл или текст.
2. Определить главную тему и уровень материала.
3. Найти подходящую главу.
4. Выбрать понятное имя файла и следующий номер.
5. Добавить лекцию и обновить список материалов в README главы.
6. Проверить ссылки и оглавление.
